## Summary
Technical decisions that shape the whole game: it is played in the browser, in JavaScript with no build step, with graphics and sounds generated by code, high scores saved in the browser, keyboard or touch screen controls (swipe and short tap) and published on GitHub Pages (https://dinamicatech.github.io/KillerFlies/), although it still works by opening index.html locally. The game's common base (index.html, screen, game loop, keyboard and touch screen) is in js/base.js; the screen measures 224×288 logical pixels and is drawn at four times that resolution.

## Decisions
- 2026-10-03 18:20 · Platform: web browser, drawing on an HTML5 Canvas. Reason: it works on any computer without installing anything and is enough for a 2D arcade game.
- 2026-10-03 18:20 · Language: JavaScript with no build step or dependencies; it is played by double-clicking `index.html`. Reason: the simplest way to run and maintain it. That is why the code goes in classic scripts (not ES modules), which work when the file is opened from disk.
- 2026-10-03 18:20 · High scores (highest wave and highest points): saved in the browser's local storage (localStorage); one player per browser, with no names or server. Reason: it covers the "for that player" of the requirements without infrastructure.
- 2026-10-03 18:20 · [replaced by 2026-10-05 13:00] Graphics and sound: pixel-art sprites defined in the code and sound effects synthesized with Web Audio; no image or sound files. Reason: nothing to load or license, and the arcade style reproduces well this way.
- 2026-10-03 18:20 · [replaced by 2026-10-03 19:30] Deployment: local only, not published on the web.
- 2026-10-03 18:20 · [replaced by 2026-10-04 10:16] Controls: keyboard only, as the requirements ask.
- 2026-10-03 18:44 · [replaced by 2026-10-04 10:16] Game base: index.html loads classic scripts from js/ that share the global object KF. js/base.js creates the 224×288 logical screen scaled to the window, stores the pressed keys in KF.teclas and runs the game loop; each part of the game is added with KF.registrar({ actualizar(dt), dibujar(ctx) }) and runs in registration order.
- 2026-10-03 19:30 · Deployment: the game is published on GitHub Pages from the root of the main branch and is played at https://dinamicatech.github.io/KillerFlies/; anyone with the link can play and high scores are saved in each player's browser. It also still works by opening index.html locally. Reason: the owner wants to give access to the game through a link.
- 2026-10-04 10:16 · Controls: keyboard or touch screen, so it can be played on a smartphone. With the keyboard, arrows and space (Player). On the touch screen you touch anywhere: swiping moves the ship and a short tap (touch and release in under 0.25 seconds, moving the finger less than 10 real pixels) shoots, starts the game at 'START GAME' and exits 'GAME OVER'. Each finger counts separately, so you can move with one and shoot with another. The page does not zoom, scroll or select text when touched.
- 2026-10-04 10:16 · Game base: index.html loads classic scripts from js/ that share the global object KF. js/base.js creates the 224×288 logical screen scaled to the window, stores the pressed keys in KF.teclas, reads the touch screen and runs the game loop; each part of the game is added with KF.registrar({ actualizar(dt), dibujar(ctx) }) and runs in registration order. From the touch screen it provides KF.tactil.dx (horizontal finger movement in logical screen pixels, not yet applied), KF.tactil.disparar (a short tap has been made) and KF.alPulsarCorto(funcion), which calls that function on each short tap.

- 2026-10-05 13:00 · Graphics and sound: sprites defined in the code (pixel-art, except the ships, which are drawn with strokes and gradients) and sound effects synthesized with Web Audio; no image or sound files. Reason: nothing to load or license.
- 2026-10-05 13:00 · Resolution: the canvas has KF.RESOLUCION (4) times more pixels per side than the 224×288 logical screen; js/base.js scales it at the start of each frame, so the whole game still measures and draws in logical pixels. Reason: so the detail of the 21st-century ships can be seen (graficos/naves-siglo-xxi).
