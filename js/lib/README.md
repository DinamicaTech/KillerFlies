# Librerías de terceros

Copiadas tal cual, sin cambios, para la partida a dos (js/red.js); el juego no las descarga de ningún CDN.

- `peerjs.min.js`: PeerJS 1.5.5 (https://peerjs.com), licencia MIT (`peerjs.LICENSE`). Conexión directa entre navegadores (WebRTC); usa el servidor gratuito de PeerJS solo para presentar los dos dispositivos.
- `qrcode.js`: qrcode-generator 2.0.4 de Kazuhiko Arase, licencia MIT (en su cabecera). Dibuja el QR de la sala.
